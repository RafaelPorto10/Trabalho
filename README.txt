LEITURA NOVA - Biblioteca Virtual

Como usar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html no navegador.
3. Crie uma conta.
4. Acesse o catálogo e clique em "Emprestar livro".
5. Acompanhe e devolva os livros em "Empréstimos".

Observação:
Esta é uma versão demonstrativa/front-end. Os usuários e empréstimos são armazenados no localStorage do navegador. Para um sistema real, seria necessário um backend, banco de dados e autenticação segura.
